CodeDance (Vibe Coding)

CodeDance (Vibe Coding) ID: #cd-intro

Apa itu Agentic Vibe Coding di CodeDance IDE dan bagaimana cara kerjanya?

CodeDance IDE adalah cloud sandbox Monaco Editor yang ditenagai Autonomous AI Coding Agent untuk membuat aplikasi web secara instan dari bahasa alami.

Langkah Penyelesaian & Panduan:
  1. 1
    Buka CodeDance IDE dari menu navigasi Deepernova atau kunjungi rute /codedance.
  2. 2

  3. 3
    AI Agent akan secara otonom merancang arsitektur berkas, menulis kode HTML/CSS/JavaScript atau React, dan menerapkan perubahan berkas dengan sistem fuzzy diff patching.
  4. 4
    Lihat hasil aplikasi secara langsung di tab Live Preview yang responsif di sisi tengah.
  5. 5
    Gunakan terminal sandbox terintegrasi untuk menjalankan perintah atau uji coba fungsionalitas.
Tips Juara & Rekomendasi Prompt:

Gunakan instruksi yang spesifik dan sertakan referensi warna atau tata letak jika ingin tampilan tertentu. AI Deepernova memahami bahasa Indonesia dan Inggris secara fasih.

CodeDance (Vibe Coding) ID: #cd-blank-preview

Solusi: Layar Live Preview kosong (blank) atau tidak merender di CodeDance IDE

Langkah cepat mengatasi kendala tampilan preview yang tidak muncul atau terjadi error sintaks pada proyek web.

Langkah Penyelesaian & Panduan:
  1. 1
    Periksa apakah berkas "index.html" ada di daftar berkas proyek (File Explorer). Aplikasi web memerlukan index.html sebagai titik awal (entry point).
  2. 2
    Pastikan tag script di dalam index.html mengarah ke berkas JavaScript yang benar (contoh: ).
  3. 3
    Buka tab "Console" di bawah Live Preview untuk melihat apakah ada pesan kesalahan JavaScript (syntax error atau missing library).
  4. 4
    Ketik perintah ke AI Agent: "Perbaiki error yang ada di console preview dan pastikan aplikasi tampil normal". AI akan memindai error dan memperbaikinya secara otomatis.
  5. 5
    Jika masih terjadi cache beku di iframe, klik tombol "Refresh Preview" (ikon putar) di pojok atas panel preview.
Tips Juara & Rekomendasi Prompt:

Jika Anda menggunakan pustaka eksternal seperti Tailwind, FontAwesome, atau Chart.js, pastikan pustaka dimuat via CDN script/link di dalam tag berkas index.html.

Solusi: Chatbot lambat merespons atau muncul pesan "Koneksi Terputus"

Langkah pemulihan cepat saat jaringan mengalami gangguan atau terjadi hambatan respons server.
