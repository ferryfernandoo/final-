# LaTeX Academic & Mathematical Publishing Pro (`.tex`)

## Aturan Utama LaTeX Bebas Error
1. Gunakan paket `amsmath`, `amssymb`, `booktabs`, `geometry`, `graphicx`, `float`, dan `hyperref`.
2. **Wajib Escape Simbol `%`, `&`, `$`, `_`, `#` di Luar Mode Matematika:** Tulis `104,7\%` (bukan `104,7%` karena `%` di LaTeX adalah komentar yang memotong habis sisa kalimat!).
3. Gunakan `\toprule`, `\midrule`, dan `\bottomrule` dari paket `booktabs` untuk tabel ilmiah.
