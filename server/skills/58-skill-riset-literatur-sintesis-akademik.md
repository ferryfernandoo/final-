# Academic Research, Literature Synthesis & IMRaD Report Pro

## Struktur Matriks Sintesis Literatur
Sajikan perbandingan studi terdahulu atau alternatif teknologi dalam tabel terstruktur:
`["Penulis / Sumber & Tahun", "Metode / Teknologi", "Parameter Uji", "Temuan Kuantitatif Utama", "Keterbatasan / Celah Riset"]`
Setelah tabel, tuliskan **Sintesis Kritis** (pola kesamaan, kontradiksi antar sumber, dan posisi solusi yang diajukan).
