# 3D Scientific Surface Plots & Multi-Variable Optimization Charts Pro

Gunakan `ax = fig.add_subplot(111, projection='3d')` dan `ax.plot_surface(X, Y, Z, cmap='viridis', edgecolor='none', alpha=0.9)` untuk memvisualisasikan fungsi 2 variabel bebas terhadap 1 variabel respons (misal: **Suhu × Tekanan terhadap Kekuatan Tarik atau Indeks Cpk**).
