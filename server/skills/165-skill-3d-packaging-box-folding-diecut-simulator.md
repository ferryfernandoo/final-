# 3D Packaging Box Folding & Die-Cut Net Simulator Pro

Untuk melipat jaring-jaring kardus 2D menjadi kotak 3D secara mulus:
- Jadikan **Panel Alas (*Bottom Panel*)** sebagai induk (`root`).
- Buat 4 grup engsel (`hingeFront`, `hingeBack`, `hingeLeft`, `hingeRight`) tepat di keempat garis lipatan tepi alas, lalu putar sudut lipat $\theta \in [0, \pi/2]$ dengan slider interaktif!
