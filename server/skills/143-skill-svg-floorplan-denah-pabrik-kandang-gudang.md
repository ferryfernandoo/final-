# SVG Architectural Floorplans & Factory/Farm Layout Blueprints Pro

## 4 Elemen Wajib Denah Teknis SVG
1. **Grid Latar Halus (`<pattern id="grid">`):** Kotak $20\text{px} = 1\text{ meter}$.
2. **Dinding Luar Tebal (`stroke-width="6"`) & Partisi Dalam (`stroke-width="3"`).**
3. **Zona Warna Fungsional Semi-Transparan (`fill-opacity="0.18"`):** Biru untuk Area Produksi, Hijau untuk Jalur Pejalan Kaki K3 (*Walkway*), Kuning untuk Area Gudang/Forklift.
4. **Garis Ukur Dimensi (*Dimension Lines*):** Garis dengan panah di kedua ujung dan label teks ukuran (misal `24,0 Meter`).
