# Animated & Interactive SVG (SMIL & CSS Stroke-Dash Animation) Pro

## Animasi Aliran Data / Fluida di Sepanjang Pipa SVG
Gunakan `stroke-dasharray="8 6"` dikombinasikan dengan `<animate attributeName="stroke-dashoffset" from="28" to="0" dur="1s" repeatCount="indefinite"/>` agar garis konektor terlihat mengalir secara *real-time* tanpa membutuhkan JavaScript!
