# 3D Audio & Vibration Frequency Spectrum (FFT) Visualizer Pro

Sangat berguna untuk aplikasi musik 3D maupun **analisis getaran mesin prediktif (*Predictive Maintenance Vibration FFT 3D*)**: petakan setiap pita frekuensi (`getByteFrequencyData(dataArray)`) ke skala tinggi `barMesh.scale.y` dan warna emisi bar 3D secara *real-time*!
