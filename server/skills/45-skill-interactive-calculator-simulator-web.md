# Interactive Business & Engineering Calculators / Simulators Pro

## Arsitektur Kalkulator Reaktif Bebas Tombol "Hitung"
Kalkulator modern memperbarui seluruh angka KPI, tabel sensitivitas, dan kurva `Chart.js` **secara instan setiap kali user menggeser slider (`input` event) atau mengubah angka**!
1. Sediakan **Preset Skenario Cepat** (tombol `"Skenario Konservatif"`, `"Skenario Standar"`, `"Skenario Optimis"`) agar user bisa mencoba berbagai kasus dalam 1 klik.
2. Tampilkan **Titik Impas (*Break-Even Point*)** secara visual pada kurva menggunakan garis horizontal/vertikal referensi.
3. Sediakan tombol **Ekspor Hasil Simulasi ke CSV** agar hasil hitungan bisa disimpan user.
