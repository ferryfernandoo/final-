# UI/UX Design System & Visual Polish Tokens Pro

## 1. Skala Spasi & Radius Konsisten (Aturan Kelipatan 4px / 8px)
- **Padding Kartu Dalam:** `p-5` (`20px`) atau `p-6` (`24px`).
- **Jarak Antar Kartu (Grid Gap):** `gap-4` (`16px`) atau `gap-6` (`24px`).
- **Sudut Membulat (*Border Radius*):** Kartu utama `rounded-2xl` (`16px`), tombol & input `rounded-xl` (`12px`), badge status `rounded-full`.

## 2. Hirarki 4 Lapisan Warna Teks & Permukaan
1. **Latar Kanvas Utama:** `bg-slate-50` (Light) / `dark:bg-slate-900` (Dark).
2. **Permukaan Kartu:** `bg-white border border-slate-200/80 shadow-sm` / `dark:bg-slate-800 dark:border-slate-700`.
3. **Teks Primer (Judul & Angka KPI):** `text-slate-900 font-extrabold` / `dark:text-white`.
4. **Teks Sekunder (Label & Keterangan):** `text-slate-500 font-medium` / `dark:text-slate-400`.
