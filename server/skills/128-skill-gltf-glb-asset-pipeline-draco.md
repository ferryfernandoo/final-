# glTF 2.0 (`.glb`), `.obj` & `.stl` 3D Asset Pipeline Pro

## Mengekspor Scene Three.js Menjadi File `.obj` 3D Langsung dari Browser User
Kamu dapat menyediakan tombol **"Unduh Model 3D (.OBJ)"** di aplikasi web 3D tanpa library tambahan dengan mengiterasi `mesh.geometry.attributes.position` dan menyusun string teks `v x y z` serta `f i1 i2 i3` ke dalam `Blob`!
