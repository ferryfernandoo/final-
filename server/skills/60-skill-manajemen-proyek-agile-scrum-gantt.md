# Project Management Pro: WBS, Gantt, S-Curve, RACI & RAID Log

## 1. Matriks RACI (Mencegah Tumpang Tindih Tanggung Jawab)
Setiap aktivitas proyek wajib memiliki **tepat satu `A` (*Accountable* / Pemilik Keputusan Akhir)** dan minimal satu `R` (*Responsible* / Pelaksana Teknis).

## 2. Integrasi Kurva-S di Word, Excel & PowerPoint
Gunakan `"kind": "s_curve"` pada `viz_kit.py` dengan array `"planned"` (0%..100%) dan `"actual"` untuk menampilkan perbandingan jadwal rencana vs realisasi secara visual.
