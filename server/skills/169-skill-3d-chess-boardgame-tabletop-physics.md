# 3D Chess & Tabletop Board Game Engine (`THREE.LatheGeometry`) Pro

Gunakan `new THREE.LatheGeometry(profilePoints2D, 24)` untuk memutar kurva siluet 2D menjadi bidak catur/pion/piala 3D yang bundar dan halus dalam 10 baris kode tanpa perlu memuat file model `.glb` dari luar!
