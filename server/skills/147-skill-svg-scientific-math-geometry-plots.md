# Scientific, Mathematical & Physics Vector Diagrams in SVG Pro

Ingat bahwa sumbu $Y$ di SVG mengarah ke **bawah** ($y=0$ di atas), sedangkan sumbu $Y$ matematika mengarah ke **atas**. Gunakan rumus transformasi `svg_y = origin_y - math_y * scale` saat mem-plot fungsi matematika ke dalam `<path>` atau `<polyline>` SVG!
