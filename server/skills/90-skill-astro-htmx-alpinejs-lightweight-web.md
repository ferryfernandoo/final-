# Lightweight Web Architecture: Astro, HTMX & Alpine.js Pro

Ketika membangun aplikasi internal atau portal konten yang harus terbuka dalam $< 100\text{ms}$ di jaringan seluler lambat, gunakan **Alpine.js** (`x-data`, `x-model`, `x-show`) yang hanya berukuran 15 KB atau **HTMX** untuk memperbarui bagian halaman langsung dari respons HTML server.
