# Vue 3 (`<script setup>`), Pinia & Nuxt 3 Pro

## Standar Kode Vue 3 Modern
- Selalu gunakan `<script setup lang="ts">`.
- Gunakan `ref()` untuk nilai primitif maupun objek/array reaktif, dan ingat untuk mengakses `.value` di dalam `<script>` (tetapi **tanpa** `.value` di dalam `<template>`).
- Gunakan `computed(() => ...)` untuk data terfilter dan total ringkasan.
