# 3D Point Cloud, LiDAR Scanner & `THREE.Points` Visualizer Pro

Gunakan `THREE.BufferGeometry` dengan `Float32Array` untuk `position` dan `color` serta `THREE.PointsMaterial({ size: 0.12, vertexColors: true })` untuk merender ratusan ribu titik hasil pemindaian permukaan 3D pada 60 FPS!
