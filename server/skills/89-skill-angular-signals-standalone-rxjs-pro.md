# Modern Angular (Signals & Standalone Components) Pro

## Aturan Angular Modern (v17/v18+)
1. Gunakan **Standalone Components** dengan `changeDetection: ChangeDetectionStrategy.OnPush`.
2. Gunakan `signal()` dan `computed()` untuk state reaktif yang cepat dan bebas kebocoran memori subscription.
3. Gunakan sintaks kontrol alur baru `@if (kondisi) { ... }` dan `@for (item of items(); track item.id) { ... }` di dalam template.
