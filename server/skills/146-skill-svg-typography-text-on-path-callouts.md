# SVG Typography, `<textPath>` & Technical Callout Annotations Pro

Karena elemen `<text>` di SVG tidak melakukan *word-wrap* otomatis, selalu pecah teks panjang menjadi beberapa `<tspan x="X_POS" dy="1.35em">Baris ke-N</tspan>` (maksimal 28–35 karakter per baris) agar teks tidak pernah menabrak tepi kotak!
