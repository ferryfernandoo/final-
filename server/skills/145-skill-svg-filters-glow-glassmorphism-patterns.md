# SVG Filters: Neon Glow, Soft Drop-Shadows & Technical Hatching Pro

## Filter Bayangan Kartu Modern (`feDropShadow`) & Pijar Neon (`feGaussianBlur`)
```xml
<defs>
  <filter id="cardShadow" x="-10%" y="-10%" width="120%" height="130%">
    <feDropShadow dx="0" dy="6" stdDeviation="8" flood-color="#020617" flood-opacity="0.45"/>
  </filter>
</defs>
```
